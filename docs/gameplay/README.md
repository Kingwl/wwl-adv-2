# 核心玩法

这个目录记录玩家可见的核心玩法功能，以及这些功能对应的自动化测试计划。

## 文件

- `features.md`：当前核心玩法功能清单，包含玩家语义、核心代码所有权、自动化覆盖和缺口。
- `test-plan.md`：核心玩法测试计划，按功能列出需要覆盖的场景、测试证据和仍未自动化的风险。

## 维护规则

- 新增、删除或改变核心玩法功能时，更新 `features.md`。
- 改变规则行为、配置形状、数值来源、胜负条件、奖励、放置、合成、目标选择、战斗、波次或生命系统时，检查 `test-plan.md` 是否需要更新。
- 只改变 UI 表现但不改变玩法语义时，优先更新 `docs/ui/`；如果 UI 改动影响玩家能否触发某个玩法路径，也同步检查这里。
- 具体测试门禁仍以 `docs/testing/gates.md` 为准。

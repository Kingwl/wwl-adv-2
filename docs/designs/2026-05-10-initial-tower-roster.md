# 设计：初期塔类型与实现批次

## 状态

Accepted

## 当前实现状态

截至 2026-05-10，第一批现有三塔映射和第二批火焰塔已进入代码、素材、UI 和测试：

- Single、Area、Slow 已分别承载弩塔、炮塔、冰霜塔的短期机制映射。
- Flame 已作为第四张可选塔卡实现，使用 `SPELL`/`MAGIC`/`FIRE` 和 `status_dot`，命中后施加 `burn` DoT。
- 毒针塔和雷霆塔仍未实现；它们分别等待 poison DoT 的塔接入和 chain 攻击模式。

## 背景

项目已经确定攻击、防御、伤害类型和种族抗性的三层伤害体系：武器形态推导攻击类型，防御类型处理武器克制，怪物种族处理冰、火、毒、电等伤害类型抗性。

在实现这套体系前，需要先明确近期要做哪些塔、哪些塔只保留设计空间。塔数量不能过多，否则会同时引入 DoT、连锁、近战范围、Debuff、素材和 UI 容量问题。初期塔应该优先复用现有 Single、Area、Slow 的攻击模式，同时覆盖足够多的攻击类型和伤害类型。

## 目标

- 定义近期要实现的基础塔名单。
- 定义暂不实现但保留设计空间的塔名单。
- 让塔类型覆盖攻击类型、伤害类型和种族抗性的代表组合。
- 控制近期实现风险，避免一次引入太多新攻击模式。
- 为后续塔配置数据化和塔卡 UI 扩展提供稳定命名。

## 非目标

- 不在本文档中确定最终数值平衡。
- 不在本文档中确定所有塔的美术资产。
- 不在第一批实现混乱塔、暗影塔、复杂 Debuff 或多伤害类型混合塔。
- 不把普通炮塔和火炮塔同时作为独立基础塔；火焰主题优先用火焰塔表达。

## 方案

### 设计原则

- 塔的玩家可见身份优先是“武器形态 + 伤害类型”，例如弩塔、冰霜塔、火焰塔。
- 攻击类型由武器形态推导，例如弩是穿刺，炮是攻城，法术是魔法。
- 伤害类型负责种族抗性和状态主题，例如冰霜减速、火焰灼烧、毒素中毒、闪电连锁。
- 第一批塔尽量复用现有三种能力：单体、溅射、减速。
- DoT 先由火焰塔引入，再复用于毒针塔。
- 连锁目标逻辑放在雷霆塔阶段，不和 DoT 同时引入。

### 分批落地

第一批：映射现有三塔。

| 当前塔 | 新设计名 | 变更 |
| --- | --- | --- |
| Single | 弩塔 | 增加 `weapon_type = CROSSBOW`、`attack_type = PIERCE`、`damage_school = PHYSICAL` |
| Area | 炮塔 | 增加 `weapon_type = CANNON`、`attack_type = SIEGE`、`damage_school = PHYSICAL` |
| Slow | 冰霜塔 | 增加 `weapon_type = SPELL`、`attack_type = MAGIC`、`damage_school = FROST` |

第二批：新增火焰塔。

- 使用 `weapon_type = SPELL`。
- 使用 `attack_type = MAGIC`。
- 使用 `damage_school = FIRE`。
- 优先实现短灼烧 DoT，避免先做大范围地面火。
- 克制亡灵、植物、冰元素等负火抗种族。

第三批：新增毒针塔。

- 使用 `weapon_type = CROSSBOW` 或 `NEEDLE`。
- 使用 `attack_type = PIERCE`。
- 使用 `damage_school = POISON`。
- 复用火焰塔引入的 DoT 框架。
- 对构装和亡灵表现较弱，因为种族毒素抗性较高。

第四批：新增雷霆塔。

- 使用 `weapon_type = SPELL`。
- 使用 `attack_type = MAGIC`。
- 使用 `damage_school = LIGHTNING`。
- 新增连锁目标选择逻辑。
- 作为构装的元素克制入口，但不替代炮塔的攻城克制。

### 为什么不用火炮塔

普通炮塔和火炮塔都容易落成“炮 + 溅射”，玩家体验重叠。初期更清楚的划分是：

| 塔 | 职责 |
| --- | --- |
| 炮塔 | 攻城 + 物理 + 慢速溅射，负责武器克制 |
| 火焰塔 | 魔法 + 火焰 + 灼烧，负责元素克制 |

这样炮塔打城甲和构装，火焰塔打怕火种族，两者不会抢同一个定位。

## 替代方案

- 同时做炮塔和火炮塔。放弃原因是两者早期都依赖炮和溅射，差异不够直观。
- 先做 8 到 10 个塔。放弃原因是 UI 容量、素材、测试和攻击模式都会膨胀。
- 先做奥术、暗影、混乱等高级塔。放弃原因是这些塔适合 Boss、精英和终局内容，早期会削弱基础克制学习。

## 风险

- 弩塔和毒针塔都可能表现为单体穿刺，需要通过 DoT、攻速和目标选择拉开差异。
- 冰霜塔和雷霆塔都属于魔法塔，需要通过控制和连锁拉开差异。
- 新增火焰塔、毒针塔和雷霆塔会分别引入 DoT 和连锁，测试覆盖必须跟随扩展。
- 6 个塔会让塔卡 UI 压力增加，可能需要分页、分组或更紧凑布局。

## 开放问题

- 第一批 UI 是否立即展示新中文名，还是先保留 Single/Area/Slow 文案直到数据化？
- 火焰塔第一版是单体灼烧、小范围溅射，还是地面持续伤害？
- 毒针塔是否允许毒素叠层，还是只刷新持续时间？
- 雷霆塔的连锁是否允许跳到已被击败或即将漏怪的目标，需要目标选择规则决定。
- 6 个塔全部进入玩家初始可选，还是部分作为后续解锁内容？

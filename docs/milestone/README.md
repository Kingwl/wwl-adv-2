# 里程碑

这个目录用于低频路线图、交付范围和历史进度检查点。当前项目状态不在这里维护，统一看 `../status.md`。

## 文件

- `godot-2d-td-merge-roadmap.md`：当前路线图和 milestone checklist。
- `archive/`：已经完成或被当前路线图吸收的历史检查点。
- `YYYY-MM-DD-release.md`：带日期的发布或检查点摘要。

## 更新规则

- 当前状态、最近验证、开放决策和下一步优先级更新到 `../status.md`。
- 只有 milestone 范围、完成标准、顺序或 checklist 完成状态变化时，才更新当前路线图。
- 历史检查点归档后不再作为实时状态来源。

## 期望

里程碑文档应说明范围、负责人、目标日期、风险和完成标准。

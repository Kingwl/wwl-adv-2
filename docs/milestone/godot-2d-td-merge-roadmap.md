# Godot 2D 塔防合成 Roadmap

## Milestone 0: Project Bootstrap

目标：建立可运行、可测试的 GDScript 工程骨架。

- [x] 创建 Godot 4.x 项目骨架。
- [x] 建立 `Game Core` 和测试项目。
- [x] 接入 GUT 测试框架。
- [x] 选择并安装一个 Godot 场景测试插件。
- [x] 增加 headless 启动检查。
- [x] 写第一个失败测试：同类型同阶塔可以合成。

完成标准：

- [x] 命令行能运行 GUT 核心规则测试。
- [x] Godot 项目能 headless 启动。
- [x] Godot 场景测试插件完成选择和安装。

## Milestone 1: Playable Prototype

目标：完成一局可玩的最小闭环。

- [x] 核心格子放置、移除和路径校验规则。
- [x] BoardView 场景格子地图和路径渲染。
- [x] 点击格子调用核心 `Board.place_tower()`。
- [x] 主场景加载和 BoardView 初始化测试。
- [x] 基础塔占位放置。
- [x] 资源钱包、放塔成本和 HUD gold 显示。
- [ ] 局内塔成长机制（合成或直接升级，待决策）。
- [x] 敌人沿路径移动。
- [x] 单一敌人生命和死亡事件。
- [x] 敌人血条显示当前生命比例。
- [x] 塔种类配置和索敌框架。
- [x] 核心塔攻击事件。
- [x] 固定 tick 战斗模拟核心。
- [x] 塔自动索敌和攻击。
- [x] 投射物飞行与真实命中判断。
- [x] 击杀奖励入账。
- [x] 波次系统设计。
- [x] 波次生成。
- [x] 通用击杀奖励和波次奖励。
- [x] 波次 HUD 和多敌人渲染。
- [x] 玩家生命和漏怪处理。
- [x] 胜利和失败条件。
- [x] 独立开始界面、暂停菜单、胜负面板、重开和返回开始流程。
- [x] 场景内选择并放置 3 种基础塔。
- [x] 固定塔栏展示塔名、价格、选中态和不可购买态。

完成标准：

- 玩家可以完成或失败一局。
- 合成、经济、战斗核心规则均有单测。
- GUT 测试覆盖正常路径和失败路径。

## Milestone 2: MVP

目标：形成有策略差异的可演示版本。

- [x] 至少 3 种塔类型。
- [ ] 至少 3 种敌人类型。
- [ ] 至少 8 波敌人。
- [ ] 基础 UI：生命、资源、波次、塔信息。
- [ ] 关卡配置数据化。
- [ ] 场景集成测试覆盖主流程。

完成标准：

- 主场景、基础 UI、波次流程有场景测试。
- GUT 测试覆盖主要核心规则和场景边界。

## Milestone 3: Beta

目标：扩大内容并稳定体验。

- [ ] 平衡第一版数值。
- [ ] 增加塔升级或局外解锁。
- [ ] 增加音效和基础特效。
- [ ] 增加关卡选择或难度选择。
- [ ] 增加回归测试覆盖已修复问题。

完成标准：

- 主要玩法 bug 都有回归测试。

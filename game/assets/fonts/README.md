# Fonts

`wwl-title-noto-sans-sc-subset.ttf` is a title-only subset of Noto Sans SC Bold from Google Fonts.

The subset includes glyphs used by title labels:

```text
WWL Tower Merge Paused Victory Defeat 大冒险 2
```

The subset keeps the Web export small while providing the Chinese glyphs required by the start screen title. The source font is licensed under the SIL Open Font License 1.1; see `OFL-NotoSansSC.txt`.
